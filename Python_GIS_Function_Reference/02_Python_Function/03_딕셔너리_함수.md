# 03. 딕셔너리 메서드

API 응답을 읽거나 코드값과 명칭을 매핑할 때 유용합니다.

| 메서드 | 기능 | 예 |
|---|---|---|
| `get(key, default)` | 키 조회, 없으면 기본값 | `row.get("name", "")` |
| `keys()` | 키 보기 | `data.keys()` |
| `values()` | 값 보기 | `data.values()` |
| `items()` | 키·값 쌍 보기 | `data.items()` |
| `update(other)` | 다른 값으로 추가·갱신 | `data.update({"a": 1})` |
| `pop(key)` | 키 제거 후 값 반환 | `data.pop("a", None)` |
| `popitem()` | 마지막 키·값 제거 | `data.popitem()` |
| `setdefault(key, default)` | 키가 없을 때 기본값 설정 | `data.setdefault("items", [])` |
| `copy()` | 얕은 복사 | `new_data = data.copy()` |
| `clear()` | 전체 비우기 | `data.clear()` |

## 실무 예제 1: API 응답의 안전한 조회
```python
response = {
    "result": {
        "count": 2,
        "items": [{"id": "A01"}, {"id": "A02"}]
    }
}
items = response.get("result", {}).get("items", [])
```

## 실무 예제 2: 코드명 매핑
```python
code_map = {"A": "간선도로", "B": "보조간선도로"}
road_type = code_map.get("A", "알 수 없음")
```

## 주의사항
- 중첩 구조에서 중간 키가 없을 수 있으므로 `get()`을 단계별로 사용합니다.
- `dict.copy()`는 얕은 복사입니다. 내부에 리스트나 딕셔너리가 있으면 완전히 분리되지 않을 수 있습니다.
