# 01. 문자열 메서드

문자열 정제는 주소·시설명·도로명·코드 속성의 전처리에서 자주 수행합니다.

| 메서드 | 기능 | 예 |
|---|---|---|
| `strip()` | 양쪽 공백/지정 문자 제거 | `" A ".strip()` |
| `lstrip()` | 왼쪽 제거 | `" A".lstrip()` |
| `rstrip()` | 오른쪽 제거 | `"A ".rstrip()` |
| `replace(old, new)` | 문자열 치환 | `"서울 시".replace(" ", "")` |
| `split(sep)` | 구분자로 나누어 리스트 반환 | `"A,B".split(",")` |
| `join(iterable)` | 문자열 목록 연결 | `",".join(["A","B"])` |
| `find(sub)` | 위치 반환, 없으면 -1 | `"서울".find("울")` |
| `count(sub)` | 포함 횟수 | `"가가나".count("가")` |
| `startswith(prefix)` | 시작 문자열 검사 | `name.startswith("서울")` |
| `endswith(suffix)` | 끝 문자열 검사 | `file.endswith(".shp")` |
| `upper()` | 대문자 변환 | `"abc".upper()` |
| `lower()` | 소문자 변환 | `"ABC".lower()` |
| `title()` | 단어 첫 글자 대문자 | `"hello world".title()` |
| `isdigit()` | 숫자로만 구성됐는지 | `"123".isdigit()` |
| `isalpha()` | 문자로만 구성됐는지 | `"abc".isalpha()` |

## 실무 예제 1: 공백과 구분자 정리
```python
raw = "  서울특별시, 강남구 "
parts = [value.strip() for value in raw.split(",")]
print(parts)
```

## 실무 예제 2: 파일 확장자 확인
```python
filename = "ROAD.SHP"
if filename.lower().endswith(".shp"):
    print("Shapefile")
```

## 실무 예제 3: 빈 문자열 처리
```python
value = "   "
value = value.strip()
if value == "":
    value = None
```

## 주의사항
- `find()`는 못 찾으면 `-1`, `index()`는 못 찾으면 오류입니다.
- `split()`의 결과는 리스트입니다.
- `join()`은 문자열을 연결하므로 숫자 목록은 먼저 문자열로 변환해야 합니다.
- 한글 주소를 단순 치환하기 전에 원본을 보존하고 표준화 규칙을 정합니다.
