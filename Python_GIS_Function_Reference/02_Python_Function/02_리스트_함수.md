# 02. 리스트 메서드와 관련 함수

| 기능 | 문법 | 설명 |
|---|---|---|
| 추가 | `items.append(x)` | 끝에 항목 하나 추가 |
| 여러 개 추가 | `items.extend(values)` | iterable의 항목들을 추가 |
| 삽입 | `items.insert(i, x)` | 지정 위치에 삽입 |
| 값 삭제 | `items.remove(x)` | 첫 번째로 일치하는 값 삭제 |
| 위치 삭제 | `items.pop(i)` | 항목을 꺼내며 삭제 |
| 전체 삭제 | `items.clear()` | 모든 항목 삭제 |
| 위치 찾기 | `items.index(x)` | 첫 일치 항목의 인덱스 |
| 개수 세기 | `items.count(x)` | 값의 등장 횟수 |
| 정렬 | `items.sort()` | 원본 정렬 |
| 역순 | `items.reverse()` | 원본 순서 뒤집기 |
| 복사 | `items.copy()` | 얕은 복사 |

## 관련 내장 함수
- `len(items)`: 항목 수
- `sorted(items)`: 정렬된 새 리스트
- `min(items)`, `max(items)`: 최소·최대
- `sum(numbers)`: 합계
- `any(items)`: 하나라도 참이면 True
- `all(items)`: 모두 참이면 True

## 실무 예제: 중복 없는 컬럼 목록
```python
columns = ["도로명", "차로수", "도로명", "폭"]
unique_columns = list(dict.fromkeys(columns))
```
순서를 유지하면서 중복을 제거합니다.

## 주의사항
- `append([1, 2])`는 리스트 자체를 하나의 항목으로 추가합니다.
- `extend([1, 2])`는 1과 2를 각각 추가합니다.
- `sort()`는 반환값이 아니라 원본을 변경합니다. `new_list = items.sort()`는 보통 의도한 결과가 아닙니다.
