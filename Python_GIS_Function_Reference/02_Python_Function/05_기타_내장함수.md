# 05. 기타 자주 쓰는 내장 함수

| 함수 | 기능 | 예 |
|---|---|---|
| `print()` | 화면 출력 | `print("완료")` |
| `type()` | 자료형 확인 | `type(value)` |
| `len()` | 길이·항목 수 | `len(rows)` |
| `range()` | 숫자 범위 생성 | `range(10)` |
| `enumerate()` | 인덱스와 값 순회 | `enumerate(files)` |
| `zip()` | 여러 iterable 묶기 | `zip(a, b)` |
| `sorted()` | 정렬된 새 리스트 | `sorted(values)` |
| `sum()` | 합계 | `sum(numbers)` |
| `min()`, `max()` | 최소·최대 | `max(values)` |
| `abs()` | 절댓값 | `abs(-10)` |
| `round()` | 반올림 | `round(3.14159, 2)` |
| `isinstance()` | 자료형 검사 | `isinstance(x, str)` |
| `int()`, `float()`, `str()` | 형변환 | `int("10")` |
| `list()`, `dict()`, `set()` | 자료형 생성·변환 | `set(values)` |
| `any()` | 하나라도 참인지 | `any(flags)` |
| `all()` | 모두 참인지 | `all(flags)` |
| `map()` | 각 항목에 함수 적용 | `list(map(str, ids))` |
| `filter()` | 조건에 맞는 항목 필터 | `list(filter(None, values))` |

## 실무 예제: 검수 결과 집계
```python
areas = [120.5, 0, 45.2, -3]
valid_areas = [area for area in areas if area > 0]

print("전체:", len(areas))
print("정상:", len(valid_areas))
print("정상 면적 합계:", round(sum(valid_areas), 2))
```

## 예외 처리: `try / except`
함수는 아니지만 파일·데이터 처리에서 필수적인 문법입니다.
```python
try:
    number = int("123")
except ValueError:
    print("숫자로 변환할 수 없습니다.")
```
예외를 무조건 숨기지 말고, 어떤 데이터에서 오류가 났는지 기록하는 것이 좋습니다.
