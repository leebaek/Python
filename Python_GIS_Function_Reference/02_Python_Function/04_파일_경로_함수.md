# 04. 파일·경로 처리

GIS 업무에서는 폴더 내 SHP·GeoJSON·CSV 파일 목록을 만들고, 경로를 조합하고, 파일을 읽고 저장하는 일이 많습니다.

## 1) `pathlib.Path` 권장
```python
from pathlib import Path

data_dir = Path("D:/GIS/data")
shp_path = data_dir / "road.shp"
print(shp_path.exists())
print(shp_path.suffix)
print(shp_path.name)
print(shp_path.parent)
```

| 기능 | pathlib 문법 |
|---|---|
| 존재 확인 | `path.exists()` |
| 파일인지 확인 | `path.is_file()` |
| 폴더인지 확인 | `path.is_dir()` |
| 확장자 | `path.suffix` |
| 파일명 | `path.name` |
| 확장자 제외 이름 | `path.stem` |
| 상위 폴더 | `path.parent` |
| 폴더 생성 | `path.mkdir(parents=True, exist_ok=True)` |
| 파일 목록 | `path.glob("*.shp")` |
| 하위 폴더까지 검색 | `path.rglob("*.shp")` |

## 2) 파일 열기: `open()`
```python
with open("memo.txt", "w", encoding="utf-8") as file:
    file.write("GIS 작업 기록")
```
- `"r"` 읽기, `"w"` 새로 쓰기/덮어쓰기, `"a"` 이어쓰기
- 한글 텍스트는 보통 `encoding="utf-8"`을 명시합니다.
- `with`를 사용하면 작업 후 파일이 자동으로 닫힙니다.

## 3) `os` 모듈
```python
import os

os.listdir("D:/GIS/data")        # 폴더 항목
os.path.join("D:/GIS", "data")   # 경로 결합
os.path.exists("D:/GIS/data")    # 존재 확인
os.makedirs("D:/GIS/output", exist_ok=True)
```
새 코드에서는 경로 조합과 탐색에 `pathlib`을 우선 추천합니다.

## 4) 실무 예제: 폴더 내 SHP 파일 찾기
```python
from pathlib import Path

folder = Path("D:/GIS/roads")
shp_files = list(folder.glob("*.shp"))

for shp in shp_files:
    print(shp.name, shp)
```

## 주의사항
- Shapefile은 `.shp` 하나만으로 완성되지 않습니다. `.shx`, `.dbf`, `.prj` 등 관련 파일을 함께 관리해야 합니다.
- 원본 폴더와 결과 폴더를 분리합니다.
- 파일명에 날짜·지역·버전 등 식별 정보를 넣으면 덮어쓰기 사고를 줄일 수 있습니다.
