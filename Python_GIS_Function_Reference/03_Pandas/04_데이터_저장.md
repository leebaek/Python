# 04. Pandas 데이터 저장

## 1) 주요 저장 함수

| 함수 | 용도 | 예 |
|---|---|---|
| `to_csv()` | CSV 저장 | `df.to_csv("out.csv", index=False)` |
| `to_excel()` | Excel 저장 | `df.to_excel("out.xlsx", index=False)` |
| `to_json()` | JSON 저장 | `df.to_json("out.json", orient="records", force_ascii=False)` |
| `to_parquet()` | Parquet 저장 | `df.to_parquet("out.parquet", index=False)` |
| `to_sql()` | DB 테이블 저장 | `df.to_sql("table", conn, if_exists="replace")` |

## 2) CSV 저장
```python
df.to_csv(
    "road_clean.csv",
    index=False,
    encoding="utf-8-sig"
)
```
- `index=False`: 인덱스를 별도 컬럼으로 저장하지 않음
- `encoding`: 한글 호환을 고려해 선택
- `columns`: 저장할 컬럼 지정

## 3) Excel 저장
```python
df.to_excel("road_clean.xlsx", sheet_name="도로", index=False)
```

## 4) 여러 시트를 하나의 Excel에 저장
```python
with pd.ExcelWriter("result.xlsx") as writer:
    roads.to_excel(writer, sheet_name="도로", index=False)
    facilities.to_excel(writer, sheet_name="시설물", index=False)
```

## 5) 저장 전 체크
```python
print(df.shape)
print(df.dtypes)
print(df.isna().sum())
```

## 주의사항
- CSV에는 자료형 정보가 충분히 보존되지 않으므로 재읽기 시 `dtype`을 다시 지정할 수 있습니다.
- Excel은 행 수 제한과 파일 크기 한계가 있습니다.
- DB 저장 시 `if_exists="replace"`는 기존 테이블을 대체할 수 있으므로 주의합니다.
- 납품 파일은 좌표계, 컬럼명, 인코딩, 파일 구성 등을 별도로 확인합니다.
