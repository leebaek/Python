# 03. Pandas 데이터 전처리

속성 정제, 조건 검색, 컬럼 가공, 중복 제거, 테이블 결합 등 실무 빈도가 높은 기능입니다.

## 1) 행·열 선택
```python
df["도로명"]                         # 컬럼 하나
df[["도로명", "차로수"]]              # 컬럼 여러 개
df.loc[df["차로수"] >= 2, ["도로명"]] # 조건과 컬럼명 기준
df.iloc[0:5, 0:3]                    # 위치 번호 기준
```

## 2) 조건 필터링
```python
filtered = df[df["차로수"] >= 2]
filtered = df[(df["차로수"] >= 2) & (df["도로등급"] == "일반국도")]
filtered = df[df["도로등급"].isin(["고속국도", "일반국도"])]
```
조건을 여러 개 결합할 때 `and`, `or` 대신 `&`, `|`를 쓰고 각 조건을 괄호로 묶습니다.

## 3) 컬럼 추가·수정·삭제
```python
df["검수상태"] = "미검수"
df = df.rename(columns={"도로명": "도로명주소"})
df = df.drop(columns=["임시컬럼"])
```

## 4) 결측값
```python
df["도로명"] = df["도로명"].fillna("미상")
df = df.dropna(subset=["도로ID"])
df["면적"] = df["면적"].fillna(0)
```
0으로 채우는 것이 의미상 맞는지 먼저 판단해야 합니다.

## 5) 자료형·문자열·날짜 변환
```python
df["도로ID"] = df["도로ID"].astype("string")
df["면적"] = pd.to_numeric(df["면적"], errors="coerce")
df["작업일"] = pd.to_datetime(df["작업일"], errors="coerce")
df["도로명"] = df["도로명"].astype("string").str.strip()
```
`errors="coerce"`는 변환할 수 없는 값을 결측값으로 바꿉니다.

## 6) 중복 제거
```python
df = df.drop_duplicates()
df = df.drop_duplicates(subset=["도로ID"], keep="last")
```
중복 기준과 어떤 행을 남길지 정하고 수행합니다.

## 7) 정렬과 그룹 집계
```python
df = df.sort_values("도로ID")
summary = df.groupby("도로등급")["차로수"].mean()
counts = df.groupby("도로등급").size()
```

## 8) 테이블 결합
```python
merged = pd.merge(
    roads, attributes,
    on="도로ID",
    how="left",
    validate="one_to_one"
)
```
- `how`: `left`, `inner`, `right`, `outer`
- `validate`: 결합 키의 관계를 검증하는 데 도움
- `concat()`: 행 방향 또는 열 방향으로 데이터 이어 붙이기

## 9) 실무 점검: 결합 전후 행 수 비교
```python
print("결합 전:", len(roads))
merged = roads.merge(attributes, on="도로ID", how="left")
print("결합 후:", len(merged))
```
행 수가 예상보다 늘었다면 오른쪽 테이블의 키 중복 여부를 확인합니다.

## 주의사항
- `inplace=True`보다 결과를 새 변수에 할당하는 방식을 권장합니다.
- 원본을 보존하고 전처리 결과를 별도 변수·파일로 저장합니다.
- `merge()` 전후 행 수, 키 중복, 결측 증가 여부를 확인합니다.
