# 01. Pandas 데이터 불러오기

Pandas는 표 형태의 속성 데이터를 다루는 대표 라이브러리입니다.

## 1) 설치와 불러오기
```bash
pip install pandas openpyxl
```
```python
import pandas as pd
```

## 2) 자주 쓰는 읽기 함수

| 함수 | 용도 | 예 |
|---|---|---|
| `pd.read_csv()` | CSV 읽기 | `pd.read_csv("data.csv", encoding="utf-8")` |
| `pd.read_excel()` | Excel 읽기 | `pd.read_excel("data.xlsx", sheet_name=0)` |
| `pd.read_json()` | JSON 읽기 | `pd.read_json("data.json")` |
| `pd.read_sql()` | SQL 쿼리 결과 읽기 | `pd.read_sql(query, conn)` |
| `pd.read_parquet()` | Parquet 읽기 | `pd.read_parquet("data.parquet")` |

## 3) CSV 실무 예제
```python
df = pd.read_csv(
    "road.csv",
    encoding="cp949",
    dtype={"도로ID": "string"},
    low_memory=False
)
```
- `encoding`: 문자 인코딩
- `dtype`: 컬럼 자료형 지정
- `usecols`: 필요한 컬럼만 읽기
- `nrows`: 읽을 행 수 제한
- `sep`: 구분자 지정

인코딩은 파일에 따라 다릅니다. UTF-8, UTF-8-SIG, CP949 등을 확인하세요.

## 4) Excel 실무 예제
```python
df = pd.read_excel(
    "facility.xlsx",
    sheet_name="시설물",
    usecols=["시설ID", "시설명", "주소"]
)
```

## 5) 대용량 파일 일부 확인
```python
for chunk in pd.read_csv("large.csv", chunksize=100_000):
    print(len(chunk))
```
`chunksize`는 파일을 나누어 읽어 메모리 부담을 줄이는 데 사용합니다.

## 주의사항
- ID·코드·우편번호는 숫자로 읽으면 앞의 0이 사라질 수 있습니다. `dtype`을 지정합니다.
- 날짜 컬럼은 `parse_dates` 또는 이후 `pd.to_datetime()`으로 변환합니다.
- 파일 전체를 읽기 전에 `nrows=5` 등으로 구조를 먼저 확인합니다.
