# 02. Pandas 데이터 확인

데이터를 수정하기 전에 행·열 구조, 자료형, 결측값, 중복을 확인합니다.

## 1) 기본 확인 함수·속성

| 기능 | 문법 | 설명 |
|---|---|---|
| 앞부분 | `df.head()` | 기본 5행 |
| 뒷부분 | `df.tail()` | 마지막 5행 |
| 크기 | `df.shape` | (행 수, 열 수) |
| 컬럼명 | `df.columns` | 컬럼 목록 |
| 자료형 | `df.dtypes` | 컬럼별 자료형 |
| 요약 | `df.info()` | 행·컬럼·결측·자료형 |
| 통계 | `df.describe()` | 수치형 통계 |
| 값 종류 | `df["등급"].unique()` | 고유값 |
| 고유값 수 | `df["등급"].nunique()` | 고유값 개수 |
| 빈도 | `df["등급"].value_counts()` | 값별 개수 |
| 결측 확인 | `df.isna().sum()` | 컬럼별 결측 수 |
| 중복 확인 | `df.duplicated().sum()` | 중복 행 수 |

## 2) 실무 점검 코드
```python
print("행/열:", df.shape)
print(df.dtypes)
print("결측값")
print(df.isna().sum())
print("중복 행:", df.duplicated().sum())
```

## 3) 특정 컬럼의 값 분포
```python
print(df["도로등급"].value_counts(dropna=False))
```
`dropna=False`를 주면 결측값도 집계에 포함합니다.

## 4) 특정 조건으로 확인
```python
df[df["차로수"] <= 0]
df[df["도로명"].isna()]
```

## 주의사항
- `info()`는 화면 출력용이며 보통 결과를 변수에 담아 분석하지 않습니다.
- `describe()`는 기본적으로 수치형 컬럼 중심입니다. `include="all"`로 범주형도 확인할 수 있습니다.
- `unique()` 결과는 배열이며 정렬된 결과를 보장하지 않습니다.
