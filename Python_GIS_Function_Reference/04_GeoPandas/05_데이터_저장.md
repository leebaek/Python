# 05. GeoPandas 데이터 저장

## 1) `to_file()`
SHP, GeoJSON, GeoPackage 등으로 저장합니다.
```python
gdf.to_file(
    "output/roads.gpkg",
    layer="roads",
    driver="GPKG"
)
```

## 2) Shapefile 저장
```python
gdf.to_file(
    "output/roads.shp",
    driver="ESRI Shapefile",
    encoding="CP949"
)
```
인코딩은 납품 환경과 데이터에 맞춰 선택합니다. Shapefile은 필드명 길이·자료형·파일 크기 등에 제약이 있습니다.

## 3) GeoJSON 저장
```python
gdf.to_file(
    "output/roads.geojson",
    driver="GeoJSON"
)
```
웹 지도나 교환용으로 유용하지만 파일이 커질 수 있습니다.

## 4) GeoPackage 저장
```python
gdf.to_file(
    "output/city.gpkg",
    layer="roads",
    driver="GPKG"
)
```
여러 레이어를 한 파일에 저장할 수 있습니다. 기존 파일에 레이어를 추가할 때는 드라이버 지원과 append 동작을 확인합니다.

## 5) PostGIS 저장: `to_postgis()`
```python
from sqlalchemy import create_engine

engine = create_engine(
    "postgresql+psycopg://user:password@localhost:5432/gisdb"
)

gdf.to_postgis(
    name="roads",
    con=engine,
    schema="public",
    if_exists="append",
    index=False
)
```
필요 패키지와 PostGIS 환경을 준비해야 합니다. 접속 비밀번호를 코드에 직접 저장하지 마세요.

## 6) 저장 전후 검증
```python
gdf.to_file("check.gpkg", layer="roads", driver="GPKG")
check = gpd.read_file("check.gpkg", layer="roads")

print("원본:", gdf.shape, gdf.crs)
print("저장 후:", check.shape, check.crs)
```

## 주의사항
- 저장 포맷에 따라 컬럼명, 자료형, 인코딩, Geometry 지원 범위가 다릅니다.
- SHP는 관련 파일 세트를 함께 전달해야 합니다.
- 저장 후 다시 읽어 행 수·컬럼·CRS·Geometry 유형을 확인합니다.
- 개발자에게 전달하는 데이터는 스키마, 좌표계, 필드 정의, 갱신 일자 등을 함께 문서화하면 좋습니다.
