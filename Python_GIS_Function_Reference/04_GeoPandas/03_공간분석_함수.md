# 03. GeoPandas 공간분석

## 1) 좌표계 설정과 변환

| 속성·메서드 | 기능 |
|---|---|
| `gdf.crs` | 좌표계 확인 |
| `set_crs()` | 좌표계 정보 지정(좌표값은 변경하지 않음) |
| `to_crs()` | 실제 좌표값을 다른 좌표계로 변환 |

```python
# 좌표계가 실제로 EPSG:4326인 데이터에만 지정
gdf = gdf.set_crs("EPSG:4326")

# 적절한 투영좌표계로 좌표 변환
projected = gdf.to_crs("EPSG:5179")
```
`set_crs()`와 `to_crs()`를 혼동하지 마세요. 잘못된 CRS 지정은 공간분석 결과 전체를 왜곡합니다.

## 2) 공간 조인: `sjoin()`
공간관계를 기준으로 두 GeoDataFrame의 속성을 결합합니다.
```python
joined = gpd.sjoin(
    points,
    polygons,
    how="left",
    predicate="within"
)
```
대표 predicate:
- `within`: 왼쪽 Geometry가 오른쪽 안에 있는가
- `contains`: 오른쪽 Geometry를 왼쪽이 포함하는가
- `intersects`: 서로 교차하는가
- `touches`: 경계만 접하는가
- `crosses`, `overlaps`, `covers`: 관계에 따라 사용

공간 인덱스와 데이터 유형에 따라 지원 predicate가 달라질 수 있습니다.

## 3) 공간 오버레이: `overlay()`
교차·합집합·차집합 등으로 실제 Geometry를 잘라 결합합니다.
```python
result = gpd.overlay(
    roads,
    admin_areas,
    how="intersection"
)
```
`how`: `intersection`, `union`, `identity`, `difference`, `symmetric_difference`

## 4) 거리 기반 분석
```python
# 투영좌표계에서 100m 버퍼 예시
roads_m = roads.to_crs("EPSG:5179")
buffer_100m = roads_m.copy()
buffer_100m["geometry"] = roads_m.geometry.buffer(100)
```

## 5) 가장 가까운 객체: `sjoin_nearest()`
```python
nearest = gpd.sjoin_nearest(
    facilities,
    bus_stops,
    how="left",
    distance_col="distance"
)
```
거리 단위는 좌표계 단위에 따릅니다. 투영좌표계에서 실행하세요.

## 6) 실무에서 자주 쓰는 분석 조합
- 도로와 행정구역 연결: `sjoin()` 또는 `overlay()`
- 시설물 주변 영향권: `to_crs()` + `buffer()`
- 시설물 최근접 도로: `sjoin_nearest()`
- 행정구역별 도로 길이: `overlay()` 후 길이 집계
- 중첩 면적 산출: `intersection()` 또는 `overlay()`

## 주의사항
- `sjoin()`은 속성 결합이며 Geometry를 잘라내는 작업이 아닙니다.
- `overlay()`는 Geometry를 실제로 분할·연산합니다.
- 조인 결과에서 한 객체가 여러 객체와 매칭되어 행이 늘어날 수 있습니다.
- 분석 전 CRS, Geometry 유형, 유효성을 확인합니다.
