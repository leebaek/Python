# 01. GeoPandas 데이터 불러오기

GeoPandas는 Pandas의 표 데이터 기능에 공간정보(Geometry)를 결합한 라이브러리입니다.

## 1) 설치와 불러오기
```bash
pip install geopandas
```
```python
import geopandas as gpd
```

## 2) `gpd.read_file()`
SHP, GeoJSON, GeoPackage 등 지원하는 공간 데이터 파일을 읽습니다.
```python
gdf = gpd.read_file("D:/GIS/road.shp")
```

자주 쓰는 옵션:
```python
gdf = gpd.read_file(
    "road.gpkg",
    layer="roads",
    columns=["road_id", "road_name"],
    rows=1000
)
```
지원 여부와 옵션은 데이터 드라이버·GeoPandas 버전에 따라 차이가 있을 수 있습니다.

## 3) PostGIS에서 읽기
```python
from sqlalchemy import create_engine
engine = create_engine("postgresql+psycopg://user:password@localhost:5432/gisdb")

gdf = gpd.read_postgis(
    "SELECT road_id, road_name, geom FROM roads",
    engine,
    geom_col="geom"
)
```
실제 비밀번호를 코드에 직접 기록하지 말고 환경변수나 안전한 설정으로 관리합니다.

## 4) 데이터 구조 확인
```python
print(gdf.head())
print(gdf.shape)
print(gdf.crs)
print(gdf.geometry.name)
print(gdf.geom_type.value_counts())
```

## 5) 특정 레이어만 읽기
GeoPackage 등 다중 레이어 파일은 레이어명을 지정할 수 있습니다.
```python
gdf = gpd.read_file("city.gpkg", layer="building")
```

## 주의사항
- 좌표계가 정의되어 있는지 `gdf.crs`로 확인합니다.
- CRS가 `None`이면 좌표계 정보를 확인하기 전 거리·면적 계산을 진행하지 않습니다.
- SHP는 컬럼명 길이, 인코딩, 필드 형식 등의 제약이 있으므로 납품 규격을 확인합니다.
