# 04. 공간 데이터 검수

GIS DB 구축·갱신에서 중요한 것은 분석 함수 자체보다 결과를 검증하는 절차입니다.

## 1) 필수 기본 점검
```python
print("행/열:", gdf.shape)
print("CRS:", gdf.crs)
print("Geometry 유형:")
print(gdf.geom_type.value_counts(dropna=False))
print("결측값:")
print(gdf.isna().sum())
print("빈 Geometry:", gdf.geometry.is_empty.sum())
print("유효하지 않은 Geometry:", (~gdf.geometry.is_valid).sum())
```

## 2) 중복 검사
```python
# 전체 속성 기준 중복
duplicate_rows = gdf[gdf.duplicated()]

# 업무상 고유해야 하는 ID 기준 중복
duplicate_ids = gdf[gdf.duplicated(subset=["road_id"], keep=False)]
```
Geometry까지 포함한 중복과 업무 키 중복은 서로 다른 검사입니다.

## 3) 속성값 검수
```python
# 필수 ID 결측
missing_id = gdf[gdf["road_id"].isna()]

# 면적이 0 이하인 객체
bad_area = gdf[gdf["area"] <= 0]

# 허용 코드 목록에 없는 값
allowed = ["A", "B", "C"]
bad_code = gdf[~gdf["road_type"].isin(allowed)]
```

## 4) 좌표 범위 확인
```python
print(gdf.total_bounds)
```
`total_bounds`는 `[minx, miny, maxx, maxy]`입니다. 좌표계에 맞는 예상 범위인지 확인합니다.

## 5) Geometry 보정 전후 비교
```python
before_invalid = (~gdf.geometry.is_valid).sum()

fixed = gdf.copy()
fixed["geometry"] = fixed.geometry.make_valid()

after_invalid = (~fixed.geometry.is_valid).sum()
print(before_invalid, after_invalid)
print(fixed.geom_type.value_counts())
```
보정이 끝났다고 검수가 끝난 것은 아닙니다. Geometry 유형, null·empty, 피처 수, 면적·길이 변화도 확인합니다.

## 6) 검수 결과 저장

```python
invalid.to_file("invalid_features.gpkg", layer="invalid", driver="GPKG")
```

## 검수 체크리스트
- [ ] 좌표계가 정의되어 있는가?
- [ ] 좌표 범위가 예상 지역과 일치하는가?
- [ ] 필수 컬럼과 자료형이 맞는가?
- [ ] 필수 ID의 결측·중복이 없는가?
- [ ] 허용 코드 외 값이 없는가?
- [ ] Geometry가 null 또는 empty가 아닌가?
- [ ] Geometry가 유효한가?
- [ ] Geometry 유형이 규격에 맞는가?
- [ ] 수정 전후 피처 수와 속성값을 비교했는가?
