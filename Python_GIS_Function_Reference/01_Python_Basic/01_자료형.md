# 01. 자료형

Python에서 데이터의 종류를 구분하는 기본 개념입니다. 속성값을 정제하거나 API 응답을 처리할 때 자료형을 정확히 파악해야 합니다.

## 1) 주요 자료형

| 자료형 | 예시 | 설명 | GIS·데이터 업무 예 |
|---|---|---|---|
| `int` | `10` | 정수 | 건물 층수, 객체 ID |
| `float` | `12.5` | 실수 | 면적, 길이, 좌표 |
| `str` | `"서울"` | 문자열 | 주소, 도로명 |
| `bool` | `True` | 참/거짓 | 검수 결과 |
| `list` | `[1, 2, 3]` | 순서가 있는 변경 가능 묶음 | 파일 목록 |
| `tuple` | `(127.0, 37.5)` | 순서가 있는 변경 불가 묶음 | 좌표 쌍 |
| `dict` | `{"name": "A"}` | 키와 값의 묶음 | API JSON 응답 |
| `set` | `{1, 2, 3}` | 중복을 허용하지 않는 묶음 | 중복 코드 제거 |

## 2) 자료형 확인과 변환

### `type()`
값의 자료형을 확인합니다.
```python
value = "123"
print(type(value))  # <class 'str'>
```

### `isinstance()`
특정 자료형인지 검사합니다.
```python
value = 123
print(isinstance(value, int))  # True
```

### `int()`, `float()`, `str()`, `bool()`
자료형을 변환합니다.
```python
text = "125"
number = int(text)
area = float("35.7")
code = str(1001)
```
주의: `"12.5"`는 `int("12.5")`로 바로 변환할 수 없습니다. `int(float("12.5"))`처럼 처리해야 하며 소수점 아래는 버려집니다.

## 3) None과 빈 값 구분
```python
value = None
if value is None:
    print("값이 없음")
```
- `None`: 값 자체가 없음을 나타냅니다.
- `""`: 비어 있는 문자열입니다.
- `0`: 숫자 0입니다.
- `[]`: 비어 있는 리스트입니다.

서로 의미가 다르므로 무조건 같은 것으로 취급하지 않습니다.

## 4) 형변환 실무 예제
```python
raw_area = " 125.6 "
area = float(raw_area.strip())
print(area)
```

## 5) 자주 하는 실수
- 문자열 `"00123"`을 정수로 바꾸면 앞의 0이 사라집니다. 코드·우편번호·관리번호는 문자열로 보관하는 것이 안전할 수 있습니다.
- 좌표와 면적은 숫자형이어야 계산할 수 있습니다.
- API에서 숫자처럼 보이는 값도 문자열로 들어올 수 있으므로 `type()`으로 확인합니다.

## 실무 메모
- ID·코드처럼 앞자리 0이 의미 있는 값은 문자열로 관리합니다.
- 결측값, 빈 문자열, 0을 구분해서 정제합니다.
