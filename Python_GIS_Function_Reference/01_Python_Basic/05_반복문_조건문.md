# 05. 반복문과 조건문

여러 파일을 일괄 처리하거나 데이터 검수 조건을 적용할 때 핵심이 되는 문법입니다.

## 1) `if / elif / else`
```python
area = 120.5
if area <= 0:
    result = "오류"
elif area < 100:
    result = "소규모"
else:
    result = "일반"
```

## 2) `for`
리스트 등 반복 가능한 객체의 항목을 하나씩 처리합니다.
```python
files = ["a.shp", "b.shp", "c.shp"]
for file in files:
    print(file)
```

## 3) `range()`
숫자 범위를 반복합니다.
```python
for i in range(5):
    print(i)  # 0~4
```

## 4) `while`
조건이 참인 동안 반복합니다.
```python
count = 0
while count < 3:
    print(count)
    count += 1
```
종료 조건을 빠뜨리면 무한 반복할 수 있습니다.

## 5) `break`, `continue`, `pass`
- `break`: 반복문 즉시 종료
- `continue`: 이번 회차를 건너뛰고 다음 회차 진행
- `pass`: 문법상 자리를 채우는 아무 작업도 하지 않는 문장

## 6) `enumerate()`
항목과 인덱스를 함께 가져옵니다.
```python
for index, file in enumerate(files, start=1):
    print(index, file)
```

## 7) `zip()`
여러 목록을 같은 순서끼리 묶습니다.
```python
columns = ["road_id", "road_name"]
labels = ["도로ID", "도로명"]
for column, label in zip(columns, labels):
    print(column, label)
```
길이가 다르면 기본적으로 짧은 쪽 길이까지만 반복합니다.

## 8) 실무 예제: 여러 파일 확장자 검사
```python
for file in files:
    if file.lower().endswith(".shp"):
        print("처리 대상:", file)
    else:
        continue
```
