# 04. 딕셔너리

키(key)와 값(value)을 연결해 저장합니다. API JSON 응답, 설정값, 코드명 매핑에 특히 유용합니다.

## 1) 생성과 값 조회
```python
feature = {
    "road_id": "R001",
    "road_name": "테헤란로",
    "lanes": 4
}
print(feature["road_name"])
print(feature.get("lanes"))
```

## 2) `[]`와 `get()` 차이
```python
feature["speed"]       # 키가 없으면 KeyError
feature.get("speed")   # 키가 없으면 None 반환
feature.get("speed", 0)  # 키가 없으면 기본값 0
```

## 3) 추가·수정·삭제
```python
feature["speed"] = 50
feature["road_name"] = "수정된 도로명"
del feature["lanes"]
```

## 4) 순회
```python
for key, value in feature.items():
    print(key, value)
```
- `keys()`: 키 목록
- `values()`: 값 목록
- `items()`: 키와 값 쌍

## 5) 딕셔너리 병합
```python
base = {"city": "서울", "year": 2026}
extra = {"count": 120}
merged = {**base, **extra}
```

## 6) 실무 예제: 코드값을 명칭으로 변환
```python
road_type = {
    "01": "고속국도",
    "02": "일반국도",
    "03": "특별시도"
}
code = "02"
name = road_type.get(code, "미등록 코드")
```

## 주의사항
- 키는 중복될 수 없습니다.
- API 응답이 중첩 딕셔너리·리스트 구조일 수 있으므로 단계별로 접근합니다.
- 코드값은 앞자리 0이 사라지지 않도록 문자열로 관리할지 검토합니다.
