# 02. 문자열

주소, 도로명, 시설명, 코드 등 GIS 속성 데이터에서 가장 자주 다루는 자료형입니다.

## 1) 문자열 생성과 인덱싱
```python
address = "서울특별시 강남구 테헤란로"
print(address[0])      # 서
print(address[:5])     # 서울특별시
print(address[-2:])    # 헤란로
```
인덱스는 0부터 시작하며 슬라이싱의 끝 인덱스는 포함하지 않습니다.

## 2) 문자열 연결과 포함 여부
```python
full_name = "서울" + "특별시"
print("강남구" in "서울특별시 강남구")  # True
```

## 3) 문자열 포매팅
```python
city = "서울"
count = 120
message = f"{city} 데이터 {count}건"
```
f-string은 로그 메시지나 파일명 생성에 유용합니다.

## 4) 문자열은 불변(immutable)
```python
name = "seoul"
name = name.upper()  # 새 문자열을 다시 할당
```
문자열 자체를 제자리에서 수정하는 방식이 아닙니다.

## 5) 실무 예제: 주소 앞뒤 공백 제거 및 표준화
```python
address = "  서울특별시 강남구  "
address = address.strip()
address = address.replace("  ", " ")
print(address)
```

## 6) 자주 쓰는 연산
| 표현 | 의미 |
|---|---|
| `a + b` | 문자열 연결 |
| `"구" in address` | 포함 여부 |
| `address[0]` | 첫 글자 |
| `address[:3]` | 앞에서 3글자 |
| `len(address)` | 글자 수 |

## 주의사항
- `replace()`는 지정한 문자열을 모두 바꿉니다. 원하지 않는 부분까지 바뀌지 않는지 확인합니다.
- 한글 주소를 단순히 글자 수로 자르는 방식은 행정구역 구조를 보장하지 않습니다.
- 대소문자, 공백, 특수문자 표준화 기준을 먼저 정합니다.
