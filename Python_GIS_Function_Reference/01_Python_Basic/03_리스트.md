# 03. 리스트

여러 값을 순서대로 보관하는 자료형입니다. 파일 경로 목록, 컬럼 목록, 처리 대상 코드 목록 등에 많이 사용합니다.

## 1) 생성과 접근
```python
files = ["seoul.shp", "busan.shp", "incheon.shp"]
print(files[0])
print(files[-1])
print(files[0:2])
```

## 2) 값 추가·삭제·수정
```python
files.append("daegu.shp")       # 끝에 하나 추가
files.extend(["ulsan.shp"])     # 여러 항목 추가
files.remove("busan.shp")       # 값으로 삭제
last_file = files.pop()         # 마지막 항목 꺼내기
files[0] = "seoul_road.shp"     # 값 수정
```
`remove()`는 해당 값이 없으면 오류가 발생합니다.

## 3) 정렬과 복사
```python
codes = [30, 10, 20]
codes.sort()              # 원본 리스트 정렬
sorted_codes = sorted(codes)  # 정렬된 새 리스트 반환
copy_codes = codes.copy()
```

## 4) 리스트 컴프리헨션
조건에 맞는 새 리스트를 간결하게 만듭니다.
```python
files = ["a.shp", "b.csv", "c.shp"]
shp_files = [f for f in files if f.endswith(".shp")]
```

## 5) 실무 예제: 처리할 컬럼 목록
```python
required_columns = ["도로명", "도로등급", "차로수"]
for column in required_columns:
    print(column)
```

## 6) 자주 쓰는 기능
| 기능 | 예 |
|---|---|
| 길이 | `len(items)` |
| 포함 여부 | `"a.shp" in files` |
| 인덱스 찾기 | `items.index("A")` |
| 개수 세기 | `items.count("A")` |
| 역순 | `items.reverse()` |

## 주의사항
- `sort()`와 `reverse()`는 원본 리스트를 변경합니다.
- `sorted()`는 새 리스트를 반환합니다.
- 리스트를 다른 변수에 단순 대입하면 같은 객체를 가리킬 수 있습니다. 별도 복사가 필요하면 `copy()`를 사용합니다.
