# Python & GIS 실무 함수 사전

이 자료는 Python 기본 문법부터 Pandas, GeoPandas까지 실무에서 자주 사용하는 기능을 찾아보기 쉽게 정리한 참고서입니다.

## 폴더 구성
- `01_Python_Basic`: 자료형, 문자열·리스트·딕셔너리, 반복문과 조건문
- `02_Python_Function`: 문자열·리스트·딕셔너리 메서드, 파일·경로, 내장 함수
- `03_Pandas`: 데이터 읽기, 확인, 전처리, 저장
- `04_GeoPandas`: 공간 데이터 읽기, Geometry, 공간분석, 검수, 저장

## 사용 방법
1. 먼저 각 문서의 함수 목록을 훑어봅니다.
2. 당장 필요한 함수부터 예제를 직접 실행합니다.
3. 업무 데이터에 적용한 뒤 `실무 메모`에 본인 사례를 추가합니다.
4. 함수의 모든 매개변수를 외우려 하지 말고, 자주 쓰는 형태부터 익힙니다.

## 중요한 구분
- `len(x)`, `str(x)`처럼 객체 바깥에서 호출하는 것은 **내장 함수**입니다.
- `text.strip()`, `items.append(x)`처럼 객체 뒤에 점(`.`)을 붙여 호출하는 것은 **메서드**입니다.
- `df["컬럼"]`, `gdf.geometry`처럼 대괄호나 속성으로 접근하는 것은 함수 호출과 구분해서 익힙니다.

예제는 학습용 가상 데이터 기준입니다. 실제 데이터에 적용하기 전에는 원본을 복사하고 좌표계·컬럼명·자료형을 확인하세요.
