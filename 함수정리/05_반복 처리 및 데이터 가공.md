# 5. 반복 처리 및 데이터 가공

## `range()`

**① 기능**\
일정한 숫자 범위를 생성하는 반복 가능한 객체를 반환한다.

**② 기본 문법**

``` python
range(start, stop, step)
```

**③ 매개변수** - `start`: 시작값. 생략하면 0 - `stop`: 끝값. 포함하지
않음 - `step`: 증가 간격. 생략하면 1

**④ 사용 예제**

``` python
for i in range(3):
    print(i)
# 0, 1, 2
```

## `enumerate()`

**① 기능**\
반복 가능한 객체를 순회하면서 인덱스와 값을 함께 제공한다.

**② 기본 문법**

``` python
enumerate(iterable, start=0)
```

**③ 매개변수** - `iterable`: 순회할 객체 - `start`: 인덱스 시작값

**④ 사용 예제**

``` python
regions = ["서울", "부산", "인천"]

for index, region in enumerate(regions, start=1):
    print(index, region)
```

## `zip()`

**① 기능**\
여러 반복 가능한 객체의 요소를 같은 순서끼리 묶는다.

**② 기본 문법**

``` python
zip(iterable1, iterable2, ...)
```

**③ 매개변수** - 두 개 이상의 반복 가능한 객체

**④ 사용 예제**

``` python
codes = ["A01", "A02"]
names = ["중앙로", "시청로"]

for code, name in zip(codes, names):
    print(code, name)
```

## `sorted()`

**① 기능**\
반복 가능한 객체를 정렬한 새로운 리스트로 반환한다.

**② 기본 문법**

``` python
sorted(iterable, key=None, reverse=False)
```

**③ 매개변수** - `iterable`: 정렬할 객체 - `key`: 정렬 기준 함수 -
`reverse`: `True`면 내림차순

**④ 사용 예제**

``` python
values = [30, 10, 20]
result = sorted(values)
# [10, 20, 30]
```

## `sum()`

**① 기능**\
숫자 요소들의 합계를 반환한다.

**② 기본 문법**

``` python
sum(iterable, start=0)
```

**③ 매개변수** - `iterable`: 숫자 요소의 반복 가능한 객체 - `start`:
합계의 시작값

**④ 사용 예제**

``` python
lengths = [100.5, 200.0, 50.5]
total = sum(lengths)
```

## `min()` / `max()`

**① 기능**\
반복 가능한 객체에서 최솟값 또는 최댓값을 반환한다.

**② 기본 문법**

``` python
min(iterable)
max(iterable)
```

**③ 매개변수** - `iterable`: 비교할 값들의 집합

**④ 사용 예제**

``` python
distances = [120.5, 80.0, 300.2]
min(distances)  # 80.0
max(distances)  # 300.2
```
