# 3. 리스트

## `append()`

**① 기능**\
리스트의 맨 뒤에 요소 하나를 추가한다.

**② 기본 문법**

``` python
list.append(item)
```

**③ 매개변수** - `item`: 추가할 요소 하나

**④ 사용 예제**

``` python
files = ["a.shp", "b.shp"]
files.append("c.shp")
```

## `extend()`

**① 기능**\
반복 가능한 객체의 요소들을 리스트 끝에 하나씩 추가한다.

**② 기본 문법**

``` python
list.extend(iterable)
```

**③ 매개변수** - `iterable`: 추가할 리스트, 튜플 등의 반복 가능한 객체

**④ 사용 예제**

``` python
seoul = ["A", "B"]
busan = ["C", "D"]
seoul.extend(busan)
# ['A', 'B', 'C', 'D']
```

## `remove()`

**① 기능**\
리스트에서 지정한 값과 일치하는 첫 번째 요소를 제거한다.

**② 기본 문법**

``` python
list.remove(value)
```

**③ 매개변수** - `value`: 제거할 값

**④ 사용 예제**

``` python
regions = ["서울", "부산", "인천"]
regions.remove("부산")
```

## `sort()`

**① 기능**\
리스트 자체를 오름차순 또는 내림차순으로 정렬한다.

**② 기본 문법**

``` python
list.sort(key=None, reverse=False)
```

**③ 매개변수** - `key`: 정렬 기준 함수 - `reverse`: `True`면 내림차순

**④ 사용 예제**

``` python
lengths = [30, 10, 20]
lengths.sort()
# [10, 20, 30]

lengths.sort(reverse=True)
```

## `pop()`

**① 기능**\
리스트에서 지정한 위치의 요소를 제거하고 그 값을 반환한다.

**② 기본 문법**

``` python
list.pop(index=-1)
```

**③ 매개변수** - `index`: 제거할 위치. 생략하면 마지막 요소

**④ 사용 예제**

``` python
files = ["a.shp", "b.shp", "c.shp"]
last_file = files.pop()
# last_file: 'c.shp'
```
