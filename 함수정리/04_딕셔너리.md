# 4. 딕셔너리

## `keys()`

**① 기능**\
딕셔너리의 모든 키를 반환한다.

**② 기본 문법**

``` python
dictionary.keys()
```

**③ 매개변수** - 없음

**④ 사용 예제**

``` python
road = {"road_name": "중앙로", "width": 20}
road.keys()
```

## `values()`

**① 기능**\
딕셔너리의 모든 값을 반환한다.

**② 기본 문법**

``` python
dictionary.values()
```

**③ 매개변수** - 없음

**④ 사용 예제**

``` python
road = {"road_name": "중앙로", "width": 20}
road.values()
```

## `items()`

**① 기능**\
딕셔너리의 키와 값을 `(key, value)` 쌍으로 반환한다.

**② 기본 문법**

``` python
dictionary.items()
```

**③ 매개변수** - 없음

**④ 사용 예제**

``` python
road = {"road_name": "중앙로", "width": 20}

for key, value in road.items():
    print(key, value)
```

## `get()`

**① 기능**\
키에 해당하는 값을 가져오며, 키가 없으면 기본값을 반환한다.

**② 기본 문법**

``` python
dictionary.get(key, default=None)
```

**③ 매개변수** - `key`: 조회할 키 - `default`: 키가 없을 때 반환할 값

**④ 사용 예제**

``` python
road = {"road_name": "중앙로"}
width = road.get("width", 0)
# 0
```
