# 2. 문자열

## `split()`

**① 기능**\
문자열을 구분자를 기준으로 나누어 리스트로 반환한다.

**② 기본 문법**

``` python
text.split(sep=None, maxsplit=-1)
```

**③ 매개변수** - `sep`: 나눌 기준 문자열. 생략하면 공백 기준으로
나눈다. - `maxsplit`: 최대 분할 횟수

**④ 사용 예제**

``` python
address = "경기도 부천시 원미구"
parts = address.split()
# ['경기도', '부천시', '원미구']

code = "A-100-서울"
code_parts = code.split("-")
```

## `join()`

**① 기능**\
문자열 리스트 등의 요소를 하나의 문자열로 연결한다.

**② 기본 문법**

``` python
separator.join(iterable)
```

**③ 매개변수** - `separator`: 요소 사이에 넣을 구분 문자열 - `iterable`:
문자열 요소를 가진 반복 가능한 객체

**④ 사용 예제**

``` python
parts = ["경기도", "부천시", "원미구"]
address = " ".join(parts)
# '경기도 부천시 원미구'
```

## `replace()`

**① 기능**\
문자열 안의 특정 문자열을 다른 문자열로 바꾼다.

**② 기본 문법**

``` python
text.replace(old, new, count=-1)
```

**③ 매개변수** - `old`: 바꿀 문자열 - `new`: 대체할 문자열 - `count`:
최대 변경 횟수

**④ 사용 예제**

``` python
name = "서울특별시 강남구"
clean_name = name.replace("특별시", "")
```

## `strip()`

**① 기능**\
문자열 양쪽 끝의 공백 또는 지정 문자를 제거한다.

**② 기본 문법**

``` python
text.strip(chars=None)
```

**③ 매개변수** - `chars`: 양끝에서 제거할 문자 집합. 생략하면 공백을
제거한다.

**④ 사용 예제**

``` python
value = "  서울시 강남구  "
clean_value = value.strip()
```

## `find()`

**① 기능**\
문자열에서 특정 부분 문자열이 처음 나타나는 위치를 반환한다.

**② 기본 문법**

``` python
text.find(sub, start=0, end=len(text))
```

**③ 매개변수** - `sub`: 찾을 문자열 - `start`, `end`: 검색 범위

**④ 사용 예제**

``` python
filename = "road_data_2026.shp"
position = filename.find("_")
# 4
```
