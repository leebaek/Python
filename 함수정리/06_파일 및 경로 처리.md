# 6. 파일 및 경로 처리

## `os.listdir()`

**① 기능**\
지정한 폴더 안의 파일 및 하위 폴더 이름을 리스트로 반환한다.

**② 기본 문법**

``` python
os.listdir(path)
```

**③ 매개변수** - `path`: 조회할 폴더 경로

**④ 사용 예제**

``` python
import os

files = os.listdir(r"D:\GIS\data")
```

## `os.path.join()`

**① 기능**\
경로 구성 요소를 운영체제에 맞는 구분자로 연결한다.

**② 기본 문법**

``` python
os.path.join(path, *paths)
```

**③ 매개변수** - `path`, `paths`: 폴더명이나 파일명 등의 경로 조각

**④ 사용 예제**

``` python
import os

folder = r"D:\GIS\data"
filename = "road.shp"
full_path = os.path.join(folder, filename)
```

## `os.path.exists()`

**① 기능**\
지정한 경로가 존재하는지 True 또는 False로 반환한다.

**② 기본 문법**

``` python
os.path.exists(path)
```

**③ 매개변수** - `path`: 확인할 파일 또는 폴더 경로

**④ 사용 예제**

``` python
import os

if os.path.exists(r"D:\GIS\data\road.shp"):
    print("경로가 존재합니다.")
```

## `glob.glob()`

**① 기능**\
와일드카드 패턴에 맞는 파일 경로 목록을 반환한다.

**② 기본 문법**

``` python
glob.glob(pathname, recursive=False)
```

**③ 매개변수** - `pathname`: 검색할 경로와 패턴 - `recursive`: `**`
패턴으로 하위 폴더까지 검색할지 여부

**④ 사용 예제**

``` python
import glob

shp_files = glob.glob(r"D:\GIS\data\*.shp")
```
