# 1. 자료형 변환

## `int()`

**① 기능**\
값을 정수형(Integer)으로 변환한다.

**② 기본 문법**

``` python
int(value)
```

**③ 매개변수** - `value`: 정수로 변환할 값

**④ 사용 예제**

``` python
int("120")    # 120
int(12.9)     # 12
```

## `float()`

**① 기능**\
값을 실수형(Float)으로 변환한다.

**② 기본 문법**

``` python
float(value)
```

**③ 매개변수** - `value`: 실수로 변환할 값

**④ 사용 예제**

``` python
float("127.5")  # 127.5
float(10)       # 10.0
```

## `str()`

**① 기능**\
값을 문자열(String)로 변환한다.

**② 기본 문법**

``` python
str(value)
```

**③ 매개변수** - `value`: 문자열로 바꿀 값

**④ 사용 예제**

``` python
str(123)       # "123"
str(127.5)     # "127.5"
```

## `bool()`

**① 기능**\
값을 참(True) 또는 거짓(False)으로 판정해 반환한다.

**② 기본 문법**

``` python
bool(value)
```

**③ 매개변수** - `value`: 참·거짓으로 판정할 값

**④ 사용 예제**

``` python
bool(1)       # True
bool(0)       # False
bool("")      # False
bool("False") # True
```
